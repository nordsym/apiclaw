# Security Policy

## Supported Versions

We release security fixes for the latest stable version of APIClaw.

| Version | Supported |
|---------|-----------|
| latest (v1.8.x) | ✅ |
| < 1.8.0 | ❌ |

## Reporting a Vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Instead, report them via email:

**security@nordsym.com**

Include as much detail as possible:
- A description of the vulnerability
- Steps to reproduce
- Potential impact
- Any suggested mitigations

We aim to acknowledge reports within 48 hours and provide a fix or mitigation plan within 14 days.

Thank you for helping keep APIClaw and its users safe.
