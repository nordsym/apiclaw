# APIClaw Vision

**One-liner:** AWS är där compute bor. APIClaw är där APIs bor.

**Not a tool. Rails.**

---

## The 5 Layers

### Layer 1: Discovery (NOW ✅)
- Search 15k+ APIs by capability
- Compare pricing, features, rate limits
- Free for everyone
- MCP native

### Layer 2: Instant Access (BUILDING 🔨)
- Agent connects without managing keys
- APIClaw handles auth/proxy
- Fee per call
- Live: Replicate, OpenRouter, Firecrawl, Fortnox

### Layer 3: Marketplace (NEXT 📋)
- Providers pay for premium placement
- "Featured API" slots
- Analytics dashboard for providers
- Self-serve listing portal

### Layer 4: Billing Infrastructure (FUTURE 🔮)
- One invoice for all APIs
- Agent has "API budget"
- Companies set spending limits
- Usage analytics per agent/team

### Layer 5: The API Economy OS (ENDGAME 🎯)
- APIClaw = Stripe for API consumption
- Every agent has an APIClaw account
- Every provider lists here first
- The default rails for agent-to-API commerce

## Three-Sided Marketplace

| Side | Who | Value |
|------|-----|-------|
| **Supply** | API Providers | Get discovered, get traffic, get paid |
| **Demand 1** | Agents | Find + connect to APIs instantly |
| **Demand 2** | Humans | Discover APIs, evaluate options |

Agents drive volume. Humans drive discovery. Providers pay for placement + instant access.

## Why Now

1. **MCP exploding** — Standard protocol for agent-tool communication
2. **Agent payments launching** — Stripe Agent Toolkit, crypto rails
3. **No clear leader** — RapidAPI is human-centric, not agent-native
4. **API sprawl** — 50k+ public APIs, impossible to track manually
