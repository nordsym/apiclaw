# Free API key signup research

Checked: 2026-10-15. Research only. No accounts were created, keys issued, emails sent, paid plans activated or production configuration changed.

## Decision

Start with **IPinfo Lite** if another credential is useful. It has the strongest combination of broad utility, an unlimited recurring free allowance, and explicit commercial redistribution rights under CC BY-SA 4.0. Implement attribution/share-alike correctly and verify the actual gateway call before adding it to callable totals. WeatherAPI, Geoapify and LocationIQ are the next commercial-application candidates, subject to reviewing shared gateway rights.

**We cannot establish how many signups would close the gap to 1,000 callable APIs. The verified incremental count from this research is 0.** This is a ranked set of 50 provider account families with documented free access, representing 53 potential API product offers because Abstract documents two and IP2Location.io explicitly includes three distinct APIs. It is not 50 new working gateway integrations. Product scope counts are conservative research groupings, not proof of key entitlements, commercial proxy permission or new coverage.

The full registry was searched: **26,703 rows**, including **23,166 unknown-pricing rows**. The shortlist is not restricted to the old 1,002 no-auth origins. Each selected family maps to existing registry names in the JSON companion. Aliases, paths, actions, countries, datasets, model choices and photo/video endpoints do not inflate counts. Rankings reflect qualitative usefulness to agents and deployment constraints, not measured customer demand.

## How to read the list

Free access is verified from a primary source. The permission column is separate: a free personal/development plan is **not permission to offer a commercial shared APIClaw gateway**, even when APIClaw charges nothing for that call. Restricted candidates are useful only for permitted owner experiments or a future per-user-key path; they are not production signup recommendations. A commercial-app permission also does not automatically authorize data resale or raw API redistribution.

Each row is one account family. Unless noted, scope is one provider API family; multiple operations are never counted as separate APIs. All actual key entitlements and incremental customer-callability counts remain unverified. Precise numeric limits are omitted where the checked source did not establish them. Signup links are entry points, not proof that approval, card requirements or practical quotas were exercised. Read-only signup-page checks returned HTTP 200 for 46 entries; OpenAlex, Europeana, Pixabay and CoinGecko returned HTTP 403 to the automated reader. These four require a human browser availability check before signup is recommended; source-confirmed free plans do not imply verified signup eligibility.

## Multiple products per signup

Abstract documents separate free IP Geolocation and Email Validation APIs under the same account service. Treat this as one signup candidate with two potential products and separate quotas. A single key working for both was not tested. Its other named registry products are not included without individual plan evidence.

IP2Location.io explicitly includes IP Geolocation, Domain WHOIS and Hosted Domain APIs with separate free quotas under each account plan. This is primary-source evidence for three product offers behind one signup, but actual keys, gateway rights and net-new coverage were not verified.

Geoapify, Europeana, WeatherAPI, Groq and OpenWeather offer several features or products behind an account, but the registry-to-product-to-key entitlement mapping has not been proven. They remain one conservative API family each. Google Gemini models, Pixabay image/video paths and the EIA energy datasets likewise remain single families.

FoodData Central documents a data.gov key. The data.gov manual documents shared default quotas across services and also a service-specific unauthorized-key error. NASA already uses this infrastructure. Existing key reuse may avoid a signup, but is not claimed without a permitted test and identity check. Do not create duplicate free accounts or rotate keys to evade quotas.

## What is required before a signup changes the callable number

1. Confirm the intended use and source terms allow APIClaw to execute on behalf of unrelated customers, and whether attribution or per-user credentials are required. Resolve contradictory pricing/terms statements.
2. Obtain the correct free plan and product-specific credential, keeping it private. Do not add a card, paid overages or a trial subscription merely to obtain a key.
